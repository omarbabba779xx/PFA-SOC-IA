# Archive pré-validation-finale

Ce dossier contient les éléments de l'itération précédente du projet, mis de côté au
lancement de la validation finale complète sous RUN_ID (voir `docs/evidence/final/`).

- `README_pre_final_redo.md` — ancien README principal, avant la reprise complète.
- `EVIDENCE.md` — ancien manifeste de preuves, contenait des champs `(à renseigner)`
  jamais complétés et des résultats calculés sur des datasets depuis identifiés comme
  contaminés ou dupliqués (voir `docs/evaluation/legacy/README.md`).
- `screenshots/` — 27 anciennes captures, produites avant l'exigence d'un RUN_ID explicite
  et d'une chaîne de traçabilité (CHAIN_OF_CUSTODY) systématique.

**Aucun chiffre ni capture de ce dossier ne doit être cité dans le rapport final.** Ils sont
conservés uniquement pour la traçabilité de la démarche (montrer d'où le projet est parti),
conformément à la règle de ne jamais supprimer une preuve historique sans traçabilité.

Voir `docs/evidence/final/PFA-FINAL-20260718-214637/` pour la validation en cours.
